Tiny tech experiments

Little coding projects, creative tech, and experiments just because I can. These are the ones I build for myself, not for a grade or a job.

The experiments so far

  • Fernwhistle

    Still being built

    A productivity and journaling app where I can change everything. It has a kanban board, a today view with an energy check-in, a calendar, notes and a junk-journal canvas. Colors, fonts, layout and navigation all live in the database instead of the code, so I can reshape the app without touching the code.

    .NET MAUI

  • WeekPeek

    My first desktop app

    It opens on its own when I start my PC and shows my day and week at a glance. I built it so I would stop checking several apps just to see my schedule.

  • Servo skull

    In progress

    A Raspberry Pi assistant that talks in character as a Warhammer 40k machine spirit. The idea and the original project belong to grimbelch. I'm building my own version because I love 40k and think it could help with everyday tasks too.
